How to Use This Site

Most students get the best results by working through these tools in order. Start with the Study Guides to build a solid understanding of each unit, then use the Glossary or Flashcards to lock in vocabulary. Once a unit feels solid, test yourself with the Quiz for instant feedback and detailed explanations on every question. In the weeks before the exam, switch flashcards and quizzes over to "All Units" mode instead of a single unit — mixing units together (rather than drilling one at a time) is one of the most well-supported study strategies for long-term retention, and it mirrors how the real AP exam jumps between topics. The games are built for the same purpose in a lower-pressure format, so use them whenever you want a break from straight review without losing study time.
